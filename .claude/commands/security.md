해커보다 먼저 보안 취약점을 찾아드려요.

**할 일**: 이 코드베이스의 보안 문제를 스캔해요.

## 1단계: 빠른 스캔
제일 흔한 문제부터 체크:

**코드에 있는 비밀**
- 찾아볼 것: API 키, 비밀번호, 토큰, 자격증명
- 확인할 곳: `.env` 파일, 설정 파일, 하드코딩된 문자열
- 검색할 것: `password`, `secret`, `api_key`, `token`

**의존성**
- `npm audit` (JS) 또는 `pip-audit` (Python) 실행
- 알려진 취약한 패키지 확인

## 2단계: 깊은 스캔
취약점 패턴 찾기:

**사용자 입력 위험**
- 문자열 연결로 만든 SQL 쿼리
- 사용자 입력을 그대로 HTML에 렌더링 (XSS)
- 사용자 입력으로 만든 명령어 (인젝션)
- 사용자 입력 기반 파일 경로 (경로 탐색)

**인증 문제**
- 평문으로 저장된 비밀번호
- 약한 세션 관리
- 로그인에 rate limiting 없음

**데이터 노출**
- 로그에 민감한 데이터
- 내부 정보 드러내는 에러 메시지
- 디버그 모드 켜져있음
