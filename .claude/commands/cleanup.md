쓸모없는 코드를 정리해드려요.

**할 일**: 불필요한 코드를 찾아서 안전하게 제거해요.

## 1단계: 안 쓰는 코드 찾기

**안 쓰는 import**
- import 해놓고 안 쓰는 것
- 쉬운 거 - 제거해도 안전

**안 쓰는 변수 & 함수**
- 선언만 하고 안 부르는 것
- 교체된 옛날 코드

**죽은 코드**
- 절대 실행 안 되는 코드 (return 뒤, 불가능한 조건)
- 주석 처리된 코드 블록
- 끝난 TODO 코드

**디버그 찌꺼기**
- `console.log` 문
- `debugger` 문
- 프로덕션 파일에 있는 테스트 코드

## 2단계: 의존성 확인
`package.json` 또는 `requirements.txt` 보기:
- 어디서도 import 안 하는 패키지
- 같은 일 하는 중복 패키지
- 업데이트해야 할 오래된 패키지

## 3단계: 제거할 것 보고

```
## 제거해도 안전

### [파일명]
- X번 줄: 안 쓰는 import 'abc'
- Y-Z번 줄: 안 쓰는 함수 'oldHelper'
- W번 줄: console.log 문

### package.json
- 안 쓰는 것: lodash (어디서도 import 안 함)
- 중복: moment.js (date-fns 대신 쓰기)

## 다시 확인 필요
[동적으로 쓰일 수 있는 것들]

## 요약
- X개 안 쓰는 import
- Y개 안 쓰는 함수
- Z개 디버그 문
- N개 안 쓰는 패키지
```

## 4단계: 정리
검토 후 할 수 있는 것:
- 찾은 것들 제거
- package.json 업데이트
- 테스트 돌려서 안 망가졌는지 확인

## 안전 제일
이런 것들은 경고해줄게요:
- 리플렉션으로 쓰일 수 있는 코드
- 동적 import
- 설정 파일에서 참조하는 코드
