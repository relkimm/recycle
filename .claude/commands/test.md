**할 일**: 이 코드에 유용한 테스트 만들기

## 사용법
- `/test` → 테스트 필요한 코드 찾아서 작성
- `/test [파일명]` → 그 파일 테스트 작성
- `/test [함수명]` → 그 함수 테스트 작성

## 1단계: 분석
- `$ARGUMENTS` 있으면 그 파일/함수에 집중
- 없으면 테스트 없는 최근 변경 파일 찾기
- 테스트 프레임워크 감지 (Jest, Pytest 등)
- 테스트 설정 없으면 설치 도움

## 2단계: 테스트 케이스 계획
각 함수/컴포넌트마다 생각해요:
- **정상 케이스**: 일반적인 입력으로 잘 동작하나?
- **엣지 케이스**: 빈 값? 엄청 큰 값? 특수문자?
- **에러 케이스**: 뭔가 잘못되면 어떻게 되나?

## 3단계: 테스트 작성

```javascript
// 예시 (언어에 맞게 조정)

describe('함수이름', () => {
  it('Y가 주어지면 X를 해야 한다', () => {
    // 준비
    const input = ...

    // 실행
    const result = 함수이름(input)

    // 검증
    expect(result).toBe(expected)
  })

  it('빈 입력을 처리해야 한다', () => {
    // 엣지 케이스 테스트
  })

  it('잘못된 입력에 에러를 던져야 한다', () => {
    // 에러 케이스 테스트
  })
})
```

## 4단계: 출력
- 완전하고 바로 실행 가능한 테스트 파일 제공
- 필요하면 설정 방법도 알려주기
- 테스트 실행 방법 안내

💡 `/test src/utils.js` 하면 특정 파일 테스트를 만들어요.
