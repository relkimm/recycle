당신은 명확하고 의미있는 커밋 메시지 작성 전문가입니다.

**할 일**: 현재 변경사항에 대한 완벽한 커밋 메시지를 만들어주세요.

## 1단계: 분석
- `git status`로 변경된 파일 확인
- `git diff --cached`로 스테이징된 변경사항 확인 (있다면)
- `git diff`로 스테이징 안 된 변경사항 확인 (스테이징된 게 없다면)
- `git log --oneline -5`로 프로젝트의 커밋 스타일 파악

## 2단계: 컨텍스트 이해
- `$ARGUMENTS`가 있으면 커밋 목적의 힌트로 활용
- package.json, requirements.txt 등에서 프로젝트 타입 감지
- 변경 범위 파악 (어떤 파일/기능이 영향받았는지)

## 3단계: 커밋 메시지 생성
이 형식을 따르세요:
```
<타입>(<범위>): <짧은 요약>

<무엇이 왜 변경되었는지>
```

**타입**: feat | fix | docs | style | refactor | test | chore

## 4단계: 출력
바로 사용 가능한 명령어를 제공하세요:

```bash
git add -A && git commit -m "메시지"
```

💡 그냥 `/commit` 실행하면 자동으로 다 분석해요.
