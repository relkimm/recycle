코드를 빠르고 쉽게 이해하도록 도와드려요.

**할 일**: 이 코드가 어떻게 동작하는지 쉽게 설명해요.

## 사용법
- `/explain` → 프로젝트 전체 개요
- `/explain [파일명]` → 그 파일 설명
- `/explain [함수/개념]` → 특정 부분 설명

## 프로젝트 전체 개요

```
## 이 프로젝트가 하는 일
[누구나 이해할 수 있는 2-3문장 요약]

## 구조
[폴더 구조와 설명]
/src
  /components  → UI 조각들
  /utils       → 도우미 함수들
  ...

## 실행 방법
[단계별 명령어]

## 알아야 할 핵심 파일
- [파일1] → 이거 함
- [파일2] → 저거 함

## 전체 흐름
[데이터/액션이 앱에서 어떻게 흘러가는지]
사용자 클릭 → 컴포넌트 호출 → API 응답 → UI 업데이트
```

## 특정 파일/함수 설명

```
## 이게 하는 일
[간단한 설명]

## 동작 방식
[단계별 분석]
1. 먼저...
2. 그다음...
3. 마지막으로...

## 입력
- [파라미터1]: 뭔지, 왜 필요한지

## 출력
- 뭘 반환/수행하는지

## 연결된 것
- 이걸 부르는 것: [뭐가 이걸 쓰는지]
- 이게 부르는 것: [이게 뭘 쓰는지]

## 예시
[간단한 사용 예시]
```
