어떤 코딩 문제든 해결하도록 도와드려요.

**할 일**: 버그를 찾아서 고쳐드려요.

## 사용법
- `/debug` → 프로젝트에서 최근 에러 찾아볼게요
- `/debug [에러 메시지]` → 그 에러를 분석해줄게요
- `/debug [문제 설명]` → 조사해볼게요

## 1단계: 문제 파악
`$ARGUMENTS`에 에러 메시지가 있으면:
- 에러 메시지 꼼꼼히 파싱
- 에러 종류와 위치 확인
- 파일과 라인 번호 찾기

에러가 안 주어지면:
- "뭐가 되야 하는데 실제로 뭐가 되나요?" 물어보기
- 최근 변경사항에서 원인 찾아보기

## 2단계: 조사
- 관련 코드 파일 읽기
- 로직 흐름 따라가기
- 흔한 문제들 체크:
  - 변수명 오타
  - import 빠짐
  - null/undefined 값
  - async/await 실수
  - 함수 인자 잘못됨

## 3단계: 설명 & 수정

```
## 근본 원인
[전문용어 없이 쉽게 설명]

## 문제 코드
[문제 코드 보여주기]

## 수정된 코드
[고친 코드 보여주기]

## 왜 이런 일이 생겼나
[다음에 피할 수 있게 간단히 설명]
```

## 4단계: 확인
- 수정이 잘 됐는지 테스트 방법 알려주기
- 아직 안 되면 더 도와드리기

💡 에러 메시지를 `/debug` 뒤에 붙여넣으면 바로 분석해드려요.
