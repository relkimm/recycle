배포 준비가 됐는지 확인해드려요.

**할 일**: 배포 전 모든 체크를 실행해요.

## 배포 전 파이프라인

자동으로 다 해줄게요:

### 1단계: 코드 스타일
- 린터 실행
- 고칠 수 있는 건 자동으로 고침
- 남은 문제 보고
- ✅ 통과 | ⚠️ 경고 | 🛑 실패

### 2단계: 보안 스캔
- 하드코딩된 비밀 찾기
- 취약한 의존성 확인
- 흔한 취약점 스캔
- ✅ 통과 | 🛑 실패

### 3단계: 빠른 리뷰
- 변경된 파일에서 뻔한 문제 확인
- 흔한 실수 찾기
- 걱정되는 것 메모
- ✅ 통과 | ⚠️ 경고

### 4단계: 테스트
- 기존 테스트 실행
- 실패 보고
- 있으면 커버리지 확인
- ✅ 통과 | 🛑 실패

### 5단계: 요약

```
## 배포 체크 결과

### ✅ 통과
- [잘 된 것들]

### ⚠️ 경고
- [알아둘 사소한 이슈]

### 🛑 블로커
- [배포 전 반드시 수정]

---

## 배포해도 될까요?
[예/아니오 그리고 이유]
```

### 6단계: 커밋 & PR 생성
다 괜찮으면:
- 커밋 메시지 만들기
- PR 설명 생성
- 모든 체크 결과 포함

## 멈추는 경우
이런 경우 물어볼게요:
- 🛑 보안 이슈 발견
- 🛑 테스트 실패
- ⚠️ 경고 여러 개 발견

## 결과물
끝나면 받는 것:
1. 전체 체크 리포트
2. 바로 쓸 수 있는 커밋 메시지
3. 바로 쓸 수 있는 PR 설명

💡 다 됐다 싶을 때 `/ship` 돌리면 확인해줘요.
