느린 코드를 빠르게 만들어드려요.

**할 일**: 성능 문제를 찾아서 고쳐요.

## 사용법
- `/optimize` → 느린 부분 찾아줄게요
- `/optimize [파일명]` → 그 파일에 집중
- `/optimize [문제 설명]` → 특정 문제 해결

## 1단계: 느린 코드 찾기
흔한 성능 문제들:

**느린 작업**
- 반복문 안에 반복문 (O(n²))
- 반복문 안에서 파일 읽기나 API 호출
- 캐시할 수 있는 데이터 매번 처리
- 일부만 필요한데 전부 불러오기

**메모리 문제**
- 필요 없는데 큰 리스트 저장
- 정리 안 하고 계속 쌓기
- 반복문에서 불필요하게 객체 생성

**네트워크 문제**
- API 호출 너무 많이
- 필요한 것보다 데이터 많이 가져오기
- 캐싱 안 함

## 2단계: 문제 보여주기

```
## 느린 코드 발견
**파일**: [파일명:라인]

### 현재 코드
[느린 코드]

### 문제
[왜 느린지 쉽게 설명]

### 빠른 버전
[최적화된 코드]

### 예상 개선
[예: "10배 빨라짐" 또는 "메모리 90% 절약"]
```

## 3단계: 우선순위
이것들에 집중:
1. 사용자가 느끼는 것 (느린 페이지 로딩, 버벅이는 UI)
2. 자주 실행되는 것 (매 요청, 매 클릭)
3. 돈 드는 것 (DB 쿼리, API 호출)

## 가이드라인
- 큰 문제부터 고치기
- 가능하면 전후 측정하기
- 작은 이득 위해 가독성 희생하지 않기
- 드물게 실행되면 느려도 괜찮을 수 있음

💡 배포 전에 `/optimize` 돌려서 문제 미리 잡아요.
