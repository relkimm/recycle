PR(Pull Request) 설명을 쉽게 만들어드려요.

**할 일**: 현재 브랜치의 PR 설명을 자동으로 생성합니다.

## 1단계: 정보 수집
- `git branch --show-current`로 현재 브랜치 확인
- `git log main..HEAD --oneline`로 커밋 내역 확인 (main 없으면 master)
- `git diff main..HEAD --stat`로 변경된 파일 확인
- `$ARGUMENTS`가 있으면 PR 목적으로 활용

## 2단계: 변경사항 분석
- 어떤 파일이 수정됐나?
- 이 변경의 주요 목적은?
- 기존 기능을 깨뜨리는 변경이 있나?

## 3단계: PR 설명 생성

```markdown
## 요약
[이 PR이 뭘 하고 왜 필요한지 2-3문장]

## 변경사항
- [주요 변경 내용]
- [관련된 것끼리 그룹화]

## 테스트 방법
1. [누구나 따라할 수 있는 테스트 방법]
2. [단계별로 설명]

## 체크리스트
- [ ] 로컬에서 테스트 완료
- [ ] 콘솔 에러 없음
- [ ] 리뷰 준비 완료
```

## 4단계: 출력
GitHub/GitLab에 바로 붙여넣을 수 있는 설명 제공

💡 `/pr` 만 실행하면 커밋 내역 보고 알아서 만들어요.
