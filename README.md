# Recycle Match

A mobile-first prototype for matching recycling pickup requests with nearby collectors.

Built with Next.js 16, React 19, and Tailwind CSS 4. Request, collection, chat, and payment screens use mock data; this repository is a product prototype.

[Demo](https://recycle-sage.vercel.app)

## Run locally

```bash
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000).

## Checks and build

```bash
npm run lint
npm run build
npm run start
```
